餐厅 Agent 教学项目需要同时运行 Python 后端和 React 前端。这个入口不再播放纯前端模拟对话。

cd examples/maison-ai
# 复制 .env.example 为 .env，填写 GOOGLE_API_KEY
python scripts/jobs.py start install
python scripts/jobs.py status install
# 安装完成后：
python scripts/dev.py --background
python scripts/dev.py --status

打开本地餐厅 Agent · 查看运行说明

没有 API Key 时，显式使用 python scripts/dev.py --mock --background。此模式仍经过真实 ADK、AG-UI 和 A2UI，但模型决策使用脚本化数据。
